# Лидерборд

Страница `/leaderboard` - топ участников по числу пройденных интервью.

## Правила подсчёта

- **Интервью** засчитывается каждому участнику (и интервьюеру, и кандидату), 
- если сессия в статусе `COMPLETED`, если есть `startedAt` и `SessionParticipant.joinedAt`. 
- Приглашённые, но не пришедшие не считаются.
- **Оценки из отзывов не учитываются.** Отзыв и оценка 0–10 видны только автору
- **Порядок**: по количеству интервью.
- В рейтинг попадают только пользователи со статусом `ACTIVE`.
- Роль под именем берётся из `Profile.role` (последний обновлённый профиль пользователя).

## API

```text
GET /leaderboard?limit=20     публичный, без JWT; limit 1..100, по умолчанию 20
→ [{ rank, userId, name, role, interviewsCount }]
```

Публичный, потому что страницу рендерит сервер Next.js, у которого нет токена пользователя.
Отдаются только имя, роль из профиля и число интервью без email, контактов и оценок.

## Frontend

- Данные запрашиваются на сервере (`entities/leaderboard/leaderboard-api.ts` →
  `shared/api/server-api.ts`) и кешируются в кеше данных Next.js на 60 секунд.
- Адрес backend на сервере: `BACKEND_INTERNAL_URL`, иначе `NEXT_PUBLIC_API_URL`. В
  `docker-compose.yml` для frontend задан `http://backend:4000` - внутри контейнера `localhost`
  указывает на сам frontend.
- Ошибка backend не роняет страницу: показывается сообщение, а причина пишется в серверный лог.

## Сид

Лидерборд считается по сидовым завершённым сессиям (`seed-data/sessions.ts`,
`session-participants.ts`). `seed-data/feedback.ts` - отзывы для страниц отзывов и истории, на
лидерборд они не влияют.
